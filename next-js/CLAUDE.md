## Repository layout

This directory (`next-js/`) is a subfolder of the larger `langgraph-projects` git repository (the `.git` root is one level up). The only project here is `hookhup/`, a Next.js app — all commands below are run from inside `hookhup/`.

`hookhup/` is currently an unmodified `create-next-app` scaffold (App Router, TypeScript, Tailwind CSS v4, ESLint) with no custom pages, components, or tests added yet.

## Commands

Run from `hookhup/`:

```bash
npm run dev     # start dev server (http://localhost:3000)
npm run build   # production build
npm run start   # serve the production build
npm run lint    # eslint
```

There is no test setup in this project yet.

## Architecture

- App Router under `hookhup/app/` — `layout.tsx` is the root layout (Geist Sans/Mono fonts via `next/font/google`), `page.tsx` is the home route.
- Path alias `@/*` maps to `hookhup/*` (see `hookhup/tsconfig.json`).
- Styling is Tailwind CSS v4 via `@tailwindcss/postcss` (`hookhup/postcss.config.mjs`), with global styles in `hookhup/app/globals.css`.
